Text action control in five tones; the default is `secondary`.

```jsx
<Button variant="primary" iconStart="plus">New project</Button>
```

Variants: primary (one per view), secondary (default, bordered), ghost (toolbars, table rows), danger (destructive confirm), link (inline). Sizes sm/md/lg map to the control-height tokens; `loading` swaps the leading icon for a spinner and disables the button.
